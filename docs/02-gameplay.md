# 02 — Геймплей

## Кор-луп

```
┌──────────────────── РАН (1 продукт) ────────────────────┐
│                                                          │
│  Старт рана                    Ход = день                │
│  ┌─────────────┐    ┌──────────────────────────────┐    │
│  │ выбор билда │    │ 1. событие дня (рандом)      │    │
│  │ основателя  │───▶│ 2. игрок тратит энергию/     │◀─┐ │
│  │ выбор идеи  │    │    деньги на действия        │  │ │
│  │ (3 случайн.)│    │ 3. конец дня: тик симуляции  │──┘ │
│  └─────────────┘    │    (трафик, конверсии, MRR,  │    │
│                     │     burn rate, churn)        │    │
│                     └──────────────────────────────┘    │
│                                                          │
│  MRR ≥ $10k ─────────▶ ПОБЕДА (экран статистики рана)   │
│  Деньги ≤ 0 ─────────▶ ПОРАЖЕНИЕ                        │
│  Мотивация ≤ 0 ──────▶ ПОРАЖЕНИЕ (выгорание)            │
└──────────────────────────────────────────────────────────┘
         Новый ран — с нуля, без мета-прогресса (v1)
```

## Ресурсы

| Ресурс | Старт | Ограничение | Роль |
|---|---|---|---|
| **Деньги ($)** | зависит от билда (~$5,000) | ≤ 0 → поражение | Главный ресурс. Тратятся на действия, инструменты, рекламу; ежемесячный burn rate |
| **Энергия (⚡)** | фикс/день (базово 10) | сгорает в конце дня, не копится | Валюта действий внутри дня |
| **Мотивация (♥)** | 100 | ≤ 0 → поражение | Медленный ресурс. Падает от провалов, кранчей, хейта; восстанавливается отдыхом и успехами. Низкая мотивация → штраф к энергии |
| **Аудитория (👥)** | 0 (или по билду) | — | Фолловеры личного бренда. Конвертируются в трафик при постах/лонче. Копится действиями «building in public» |

Взаимосвязь: мотивация < 30 → энергия/день −2 (выгорание тлеет); мотивация < 15 → −4 и растёт шанс негативных личных событий.

## Билды основателя (выбор на старте рана)

| Билд | Деньги | Особенности |
|---|---|---|
| **Кодер** | $4,000 | Действия разработки −50% энергии; действия маркетинга +50% энергии; старт аудитории 0 |
| **Маркетолог** | $4,000 | Маркетинг −50%, разработка +50% (или дороже деньгами — «нанять фрилансера»); старт аудитории 500 |
| **Универсал** | $6,000 | Без модификаторов, больше денег |
| **Экс-корпорат** | $12,000 | Все действия +25% энергии (отвык от рук), большой запас денег, мотивация падает быстрее |

Баланс-цель: ни один билд не доминирует; разные стратегии прохождения.

## Ход (день)

1. **Утро:** показывается событие дня, если выпало (см. 04). Часть событий требует выбора.
2. **День:** игрок выбирает действия из списка, пока есть энергия (и деньги — часть действий стоит и то и другое). Можно закончить день с неистраченной энергией (сгорает).
3. **Тик симуляции:** пересчёт воронки и ресурсов (см. 03), лог дня («+34 визита, 2 регистрации, 1 отписка»).

### Время и стадии

Ход = день **всю игру**. Стадии — только контентные маркеры (веса событий, доступность найма), масштаб времени не меняется:

| Стадия | MRR | Что меняется |
|---|---|---|
| Гараж | $0 – $1k | База: выживание, валидация, первый лонч |
| Тракшн | $1k – $10k | Открывается найм NPC-помощников, события про рост/конкурентов |

Против рутины поздних дней — **фаст-форвард «повторить день ×7»**: прогоняет неделю с теми же действиями, прерывается событием или порогом (деньги/мотивация упали, MRR-веха).

Целевая длительность победного рана: **40–90 минут** реального времени; типичное поражение в «Гараже»: 10–20 минут.

## Действия (каталог v1)

Свобода полная: с первого дня доступно почти всё. «Правильный порядок» (методология) не навязывается — но симуляция наказывает: лонч без валидации → низкий PMF-множитель → конверсии в разы хуже (см. 03).

| Действие | ⚡ | $ | Эффект |
|---|---|---|---|
| Исследовать нишу (валидация) | 3 | 0 | Открывает скрытые параметры ниши (спрос, конкуренция), повышает PMF будущего продукта |
| Изучить конкурента-донора | 2 | 0 | +PMF, открывает фичи/цены донора |
| Пилить MVP | 4 | 0 | +прогресс продукта (нужен для лонча) |
| Добавить фичу | 4 | 0 | +качество продукта; после 3-й фичи — убывающая отдача и +шанс багов («ещё одна фича» — ловушка) |
| Чинить баги | 2 | 0 | Снижает churn |
| Задеплоить / инфраструктура | 2 | 50 | Требуется для лонча; +ежемесячные расходы на инфру |
| Написать лендинг | 3 | 0 | +конверсия визит→регистрация |
| Пост в канал (SEO/соцсеть/форум) | 2 | 0 | +трафик по выбранному каналу, +аудитория |
| Запустить рекламу | 1 | 100+ | Платный трафик, CAC зависит от канала и качества лендинга |
| Лонч (Product Cave и т.п.) | 5 | 0 | Разовый всплеск трафика × размер аудитории × качество подготовки |
| Общаться с юзерами | 2 | 0 | +мотивация (если юзеры довольны), −churn, инсайты (открывают проблемы продукта) |
| Поднять/изменить цену | 1 | 0 | Меняет конверсию и ARPU |
| Подключить платежи | 2 | 0 | Требуется, чтобы MRR > 0 |
| Смотреть метрики | 1 | 0 | Открывает детальную аналитику за период |
| Отдых | все | 0 | +мотивация, день без прогресса |
| Нанять NPC-помощника (стадия Тракшн) | 2 | 500+/мес | Автоматизирует класс действий (саппорт-гоблин, эльф-дизайнер) |

Точный список, стоимости и формулы эффектов — баланс-параметры (см. 03), в коде выносятся в конфиг.

## Анти-паттерны, наказываемые молча

- Лонч без валидации → PMF-множитель 0.1–0.3 вместо 0.7–1.0
- Распыление на 2+ канала одновременно → эффективность каждого −60% («1 канал»)
- Фичи после 3-й без запроса юзеров → баги, churn, ноль прироста конверсии («1 фича»)
- Кранч (тратить всю энергию на работу много дней подряд) → обвал мотивации
- Игнор саппорта → churn растёт
