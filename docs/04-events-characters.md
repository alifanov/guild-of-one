# 04 — События и персонажи

Рандома должно быть много — это симуляция реальной жизни запуска. События — главный носитель иронии и фэнтези-антуража.

## Система событий

- Шанс события в день: ~35% (баланс-параметр); фаст-форвард «×7» прерывается событием
- Вес события зависит от стадии и состояния (нет прода — не падает прод; нет юзеров — нет хейта)
- Типы: **мгновенные** (применили эффект, показали) и **с выбором** (2–3 опции с разными ценами/рисками)
- Контент-цель MVP: **50+ событий**

## Категории и примеры

| Категория | Примеры |
|---|---|
| **Рынок** | Конкурент-лич скопировал твою фичу (−трафик); ниша хайпанула (+спрос ×2 на неделю); донор поднял цены (+твоя конверсия) |
| **Технические** | Прод упал в пятницу вечером (гном-девопс требует пива и $200); Wyvercel сменил тарифы (+инфра-расходы); критический баг у крупного клиента (выбор: чинить ночью −мотивация / забить +churn) |
| **Соцсети/лонч** | Пост завирусился (+аудитория ×3); гоблины-хейтеры в комментах (−мотивация, выбор: отвечать/игнорить); фичеринг на Product Cave (+всплеск трафика); шитпост про тебя от крупного аккаунта |
| **Личные** | Простуда (энергия −50% на 3 дня); друг зовёт в отпуск (выбор: −$500 +мотивация / отказаться −мотивация); «а не пойти ли обратно в найм» — оффер-искушение (выбор: отказаться / принять = конец рана с особой концовкой) |
| **Деньги** | Дракон-инвестор предлагает $50k за 20% (выбор: взять — деньги сейчас, но −доля MRR в счёте / отказать); налоговая сова прислала письмо (−$); неожиданный annual-план от клиента (+$) |
| **Юзеры** | Фанат-паладин пишет хвалебный тред (+мотивация +аудитория); churn-демон забрал 5 клиентов за ночь; юзер просит фичу «без которой уйдёт» (выбор-ловушка) |

## Персонажи (фэнтези, чисто антураж)

Роль: **лица случайных событий** + NPC-помощники для найма. Не сюжет, не диалоговые деревья — портрет + реплика в один-два предложения с самоиронией.

| Персонаж | Роль в событиях | Наём (стадия Тракшн+) |
|---|---|---|
| **Гном-девопс** | Технические инциденты | Автоматизирует деплой/инциденты, $1k/мес |
| **Эльфийка-дизайнер** | События про лендинг/бренд | +качество лендинга пассивно, $1.5k/мес |
| **Дракон-инвестор** | Деньги-события, искушения | — |
| **Гоблины-хейтеры** | Соцсети, комменты | — |
| **Churn-демон** | Отписки, «почему они уходят» | — |
| **Оракул-аналитик** | События про метрики, инсайты | Авто-«смотреть метрики», $800/мес |
| **Саппорт-гоблин (перевоспитанный)** | — | Автоматизирует общение с юзерами, $600/мес |
| **Лич-конкурент** | Рыночные события | — |
| **Налоговая сова** | Регуляторка, платежи | — |
| **Фанат-паладин** | Позитив от юзеров | — |

Контент-цель MVP: 8–10 персонажей с пиксель-портретами (2 состояния: нейтрал/эмоция).

## Формат события (данные)

```ts
{
  id: 'prod_down_friday',
  category: 'tech',
  stageWeights: { garage: 0, traction: 3 },              // вес по стадиям
  requires: { deployed: true },
  character: 'gnome_devops',
  title: { ru: 'Прод упал. Пятница, 23:40', en: 'Prod is down. Friday, 11:40pm' },
  choices: [
    { text: {...}, effects: { energy: -4, motivation: -5 },            // чинить ночью
      risk: null },
    { text: {...}, effects: { money: -200 },                           // заплатить гному
      risk: null },
    { text: {...}, effects: {}, risk: { churnSpike: 0.3, prob: 0.5 } } // забить
  ]
}
```

Все тексты — i18n-объекты (ru/en) с первого дня.
