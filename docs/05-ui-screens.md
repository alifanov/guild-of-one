# 05 — UI и экраны

## Визуальный стиль

- **Пиксель-арт**: персонажи, иконки действий/ресурсов, иллюстрации событий (референсы: Punch Club, Kingdom, Coffee Talk)
- UI-рамка — «игровой дашборд»: пиксельные панели + читаемые цифры/графики (цифры НЕ пиксельным шрифтом в таблицах — читаемость важнее)
- Пиксельный шрифт — только в заголовках/акцентах; основной текст — обычный
- Тёмная тема по умолчанию (среда индихакера); светлая — опционально, не в MVP
- Ассеты: спрайт-листы PNG; генерация пиксель-арта — AI + ручная чистка

## Экраны

```
[Титул] → [Новый ран: билд] → [Новый ран: выбор идеи из 3] → [ИГРА] → [Конец рана]
                                                                ↑ модалка события дня
```

### 1. Титульный экран
Логотип, «Новый ран», «Продолжить» (если есть сейв), выбор языка RU/EN, звук on/off.

### 2. Старт рана
Шаг 1 — карточки билдов основателя (портрет + статы + особенности). Шаг 2 — 3 карточки идей (легенда, намёки на нишу; истинные параметры скрыты до валидации).

### 3. Главный игровой экран (ядро)

```
┌──────────────────────────────────────────────────────────┐
│ День 47 · Стадия: Гараж    💰 $3,210  ⚡ 6/10  ♥ 71  👥 830 │  ← шапка: ресурсы
├──────────────────────────────┬───────────────────────────┤
│  ВОРОНКА (сегодня/тренд)     │   ДЕЙСТВИЯ                │
│  визиты      124  ▁▂▄▅▄      │  [Пилить MVP      4⚡]    │
│  регистрации   6  (4.8%)     │  [Пост в канал    2⚡]    │
│  платящие     41  (+1/-0)    │  [Чинить баги     2⚡]    │
│  MRR        $820  churn 6%   │  [Реклама   1⚡ $100]    │
│  график MRR ▁▁▂▂▃▃▄          │  [Отдых]  [ещё…]         │
├──────────────────────────────┴───────────────────────────┤
│  ЛОГ: «Гоблин оставил коммент: „поделка“. −2 ♥»          │
│                                    [Закончить день ▶]    │
└──────────────────────────────────────────────────────────┘
```

- Панель продукта (вкладка/секция): качество, фичи, баги, цена, статус (деплой/платежи)
- Панель каналов: вложения и отдача по каждому каналу
- Детальная аналитика — по действию «Смотреть метрики» (CAC/LTV/retention)

### 4. Модалка события
Пиксель-портрет персонажа + реплика + заголовок + (опционально) 2–3 кнопки выбора с ценами. Мгновенные события можно показывать тостом в логе.

### 5. Конец рана
Победа/поражение, причина, график MRR и денег за ран, ключевая статистика (дней, пик MRR, потрачено, аудитория), самоироничный вердикт («Умер от выгорания на 89-й день. Классика.»), «Новый ран», кнопка «Поделиться» (генерация картинки-карточки результата — желательно в MVP, это виральная петля).

## Адаптив

- Десктоп — приоритет: трёхпанельный дашборд
- Мобилка — адаптив: панели складываются в вертикальный стек с табами (Воронка / Действия / Продукт), шапка ресурсов — sticky. Полная играбельность, но без пиксель-перфекционизма
- Все интерактивные элементы — `cursor-pointer`, тап-таргеты ≥ 44px

## Звук (nice to have, не блокер MVP)

Чиптюн-эмбиент + короткие SFX (деньги, событие, лонч). Выключатель на титуле.
