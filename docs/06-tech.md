# 06 — Техника и скоуп MVP

## Стек

| Слой | Выбор |
|---|---|
| Фреймворк | **Next.js** (App Router) — статический экспорт возможен, бэкенд не нужен |
| UI | Tailwind + shadcn/ui (панели, модалки, табы) + кастомные пиксель-компоненты |
| Состояние | Zustand (один store рана) — вся игра клиентская |
| Графики | Recharts или лёгкий кастом-SVG (MRR/деньги/воронка) |
| RNG | Seeded PRNG (напр. mulberry32) — весь рандом от seed рана |
| i18n | next-intl (или простой словарь ru/en) — все игровые тексты в JSON-словарях с первого дня |
| Хостинг | Vercel |

Бэкенда, БД и аутентификации в v1 **нет** — игра полностью в браузере.

## Архитектура

```
Движок симуляции (чистый TS, без React)      UI (React)
┌─────────────────────────────────┐          ┌────────────────────┐
│ state: GameState                │  actions │ экраны, панели,    │
│ reducer: applyAction / endDay   │◀────────│ модалки событий    │
│ balance.ts — ВСЕ числа баланса  │  state   │                    │
│ content/: ниши, события,        │─────────▶│                    │
│   персонажи, действия (данные)  │          └────────────────────┘
└─────────────────────────────────┘
```

- **Движок отделён от UI**: чистые функции `(state, action, rng) → state`. Это даёт юнит-тесты баланса и быстрые авто-симуляции («бот играет 1000 ранов» для тюнинга)
- **Контент = данные**: ниши, события, персонажи, действия — декларативные объекты, добавление контента не трогает код движка
- **balance.ts** — единый конфиг всех чисел (стартовые деньги, конверсии, веса событий)

## Сохранения

- `localStorage`: автосейв состояния рана после каждого хода + лучшие результаты (список прошлых ранов для локальной статистики)
- Версионирование сейва (`saveVersion`) с простой миграцией/сбросом при несовместимости
- «Зашёл и играешь»: никакой регистрации

## Тесты (минимум)

- Юнит-тесты движка: тик дня, условия победы/поражения, эффекты событий
- Скрипт авто-симуляции для баланса: N ботов с разными стратегиями → распределение исходов (валидирует, что анти-паттерны действительно проигрывают, а «правильная» стратегия достижимо побеждает)

## Скоуп MVP (= полноценная играбельная игра)

**Входит:**
- Полный ран: старт (билд + идея) → игра до $10k MRR / смерти → экран конца рана
- Все 4 ресурса, воронка целиком, burn rate, фаст-форвард «повторить день ×7»
- 4 билда основателя, 15+ ниш, каталог действий, NPC-найм
- 50+ событий, 8–10 персонажей с пиксель-портретами
- Пиксель-арт стиль, тёмная тема
- i18n RU/EN
- localStorage-сейв, seeded RNG
- Адаптив под мобилку
- Шер-карточка результата рана (виральная петля)

**Не входит (после MVP):**
- Мета-прогресс между ранами
- Аккаунты, БД, лидерборды, daily seed challenge
- Звук (nice to have), светлая тема
- Обучающий ментор-фидбек (v1 наказывает молча)
- Монетизация (решение отложено)

## Порядок разработки (рекомендация)

1. Движок симуляции + balance.ts + авто-симуляция (баланс на ботах, без UI)
2. Кор-UI: главный экран, ход, конец рана (плейсхолдер-графика)
3. Контент: ниши, события, персонажи (тексты ru/en)
4. Пиксель-арт и полировка UI
5. Шер-карточка, адаптив, i18n-вычитка
6. Плейтесты и тюнинг баланса
