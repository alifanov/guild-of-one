# Guild of One — требования

> Название: **Guild of One** · домен **guildof.one** (зарегистрирован).


Пошаговый roguelike-симулятор запуска продукта соло-основателем. Один ран = один продукт: от идеи до **$10k MRR** или смерти (деньги = 0 или выгорание = 0). Пиксель-арт, самоирония, фэнтезийные персонажи для антуража. Методологическая база — пайплайн [ai-garage-launch](https://github.com/alifanov/ai-garage-launch) (идея → валидация → канал → спек → билд → деплой → лонч → метрики → платежи), но в игре — **полная свобода действий**, пайплайн лишь «правильный путь», отклонение от которого наказывается цифрами.

## Ключевые решения (зафиксировано с владельцем)

| Вопрос | Решение |
|---|---|
| Жанр | Пошаговый симулятор + roguelike (1 продукт = 1 ран), без текстового квеста |
| Победа | $10,000 MRR |
| Поражение | Деньги ≤ 0 **или** мотивация (выгорание) ≤ 0 |
| Мета-прогресс между ранами | Нет (v1) |
| Ресурсы | Деньги (главный), энергия (фикс/день), мотивация, аудитория |
| Время | Пошагово, ход = день всю игру; фаст-форвард «повторить день ×7» против рутины |
| Рандом | Максимум случайностей — «симуляция реальной жизни» |
| Ход | Игрок выбирает действия; стоят энергию и/или деньги |
| Воронка | Полностью видна игроку (визиты → signup → paid, churn, CAC/LTV) |
| Фидбек на ошибки | Молча наказывать цифрами, без менторских объяснений (v1) |
| Тон | Самоирония, индихакерские мемы + фэнтези-персонажи (антураж, лица событий) |
| Стиль | Пиксель-арт |
| Билд основателя | Выбирается на старте рана (Кодер / Маркетолог / Универсал…) |
| Расходы | Постоянный burn rate (жизнь + инфраструктура) |
| Пайплайн | Свобода вместо жёсткой последовательности |
| Платформа | Десктоп-браузер приоритет, мобилка адаптивом |
| Языки | Русский + английский с самого начала |
| Сохранения | localStorage, без регистрации |
| Стек | Next.js + Tailwind + shadcn (основной — Next.js) |
| MVP | Полноценная играбельная игра: события, персонажи, этапы, пиксель-арт |
